User Guide

Split-LAMP Primer Design Tool

Everything you need to design Split-LAMP primers for miRNA detection.

🎯 Purpose

This tool generates Split-LAMP primer sets for detecting microRNA (miRNA) targets. Unlike traditional LAMP, Split-LAMP uses the miRNA itself as a primer (F2 and/or B2), allowing direct detection without reverse transcription.

F2 Only mode — one miRNA acts as the F2 primer. The algorithm generates B2 and all supporting primers around it.

F2 and B2 (AND-gate) mode — two miRNAs act as F2 and B2. A positive signal requires both miRNAs to be present simultaneously, which reduces false positives and enables multiplex detection.

🚀 How to Use

1

Select Architecture

Choose F2 Only if you have one miRNA target, or F2 and B2 (AND-gate) if you want to detect two miRNAs simultaneously.

2

Enter miRNA Name and Sequence

Type the miRNA name (e.g. miR-21-5p) and paste its sequence. Accepted formats: plain sequence or FASTA. Accepts A, C, G, T, and U — U is automatically converted to T. Example: UAGCUUAUCAGACUGAUGUUGA

3

Configure Design Options

Choose whether to generate loop primers (LF, LB), optimize for specificity, check for hairpin structures, and calculate ΔG values. All options are on by default and recommended for most uses.

4

Click Generate Primers

The tool will compute your full primer set and switch to the Primer Output tab automatically.

5

Review and Edit

All primers are editable directly in the output. Changes to F2 automatically update FIP and the Template Ultramer in real time. Use the Reset button next to any primer to restore the original generated sequence.

6

Copy and Order

Use the Copy button next to any primer to copy the sequence to your clipboard for ordering.

📋 Understanding the Output

Template Ultramer

The Template Ultramer is a synthetic DNA strand that encodes all primer-binding regions. It is color-coded to show where each primer component sits within the full sequence. Hover over any highlighted region to see which primer it corresponds to.

Primer Statistics

Stat What it means Typical range
Length Number of base pairs in the primer 18–30 bp for most primers; ~22 bp for miRNA-derived F2/B2
GC Content Percentage of G and C bases. Higher GC means stronger binding. 40–60%
Tm Melting temperature. The temperature at which half the primer-template duplexes dissociate. 58–65°C for LAMP
ΔG (5' end) Gibbs free energy of the first 6 bp. Less negative = less stable = better for avoiding secondary structure at the 5' end. Greater than –9 kcal/mol preferred
ΔG (3' end) Gibbs free energy of the last 6 bp. A very negative 3' ΔG can cause non-specific extension. This is the more critical value. Greater than –9 kcal/mol preferred
Hairpins Whether the primer folds back on itself. None is ideal. Weak is usually acceptable. Strong may interfere with amplification. None or Weak
Dimers Whether this primer has 3' complementarity with other primers in the set. Cross-dimers can reduce amplification efficiency. None or Weak

✏️ Editing Primers

All primers on the output tab are directly editable. Click into any sequence box and type to modify it.

  • Editing F2 automatically recalculates FIP and the Template Ultramer.
  • All stats (length, GC, Tm, ΔG) update instantly as you type.
  • If you enter an invalid character, an error message appears and the cascade does not update until the sequence is valid.
  • Click Reset next to any primer to restore the originally generated sequence.

⚠️ Editing a primer changes only that primer's sequence. The algorithm does not re-run automatically. If you make large changes, verify that the edited primer still satisfies LAMP design rules (length, GC, Tm).

🔬 Thermodynamic Methods

All Tm and ΔG values are calculated using the SantaLucia 1998 nearest-neighbor model with the Owczarzy magnesium correction, which is appropriate for LAMP reaction conditions.

  • Default Mg²⁺: 8 mM (typical for LAMP)
  • Default Na⁺: 50 mM
  • Default dNTPs: 0.8 mM (used to calculate free Mg²⁺)
  • Default primer concentration: 0.25 µM
  • ΔG is evaluated at 65°C, the standard LAMP reaction temperature
  • Primers shorter than 14 bp use the Wallace rule for Tm instead

❓ Troubleshooting

  • Invalid characters error — only A, C, G, T, and U are accepted. Remove spaces, numbers, or other characters. FASTA headers (lines starting with >) are stripped automatically.
  • Sequence too short — miRNA sequences are typically 18–25 nt. Sequences under 14 nt use the Wallace rule for Tm, which is less accurate.
  • Reset not working — Reset restores the sequence from when primers were last generated. If you have not generated primers yet, Reset has nothing to restore.
  • Strong hairpin warning — try adjusting the primer sequence by 1–2 bases and check if the warning changes. A strong hairpin at the 3' end is the highest priority to resolve.
  • Template Ultramer looks wrong — if you edited F2, the template updates automatically. If another primer was edited manually, the template does not update for that change. Regenerate primers for a clean baseline.
